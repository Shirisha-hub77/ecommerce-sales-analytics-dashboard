# E-Commerce Sales Analytics Dashboard

## Project Overview
An interactive E-Commerce Sales Analytics Dashboard developed to analyze sales performance, order trends, delivery efficiency, product categories, and payment methods.

## Dashboard KPIs
- **Total Revenue:** 15,209,427
- **Total Orders:** 1,000
- **Average Delivery Time:** 5.55 days
- **Average Order Value:** 5,201.42

## Key Features
- Sales by city
- Average quantity by city
- Monthly sales trend
- Payment mode distribution
- Interactive filters for city, category, and payment mode

## Tools & Technologies
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Slicers and interactive dashboard elements
- Data visualization and KPI reporting

## Dashboard Preview
![E-Commerce Analytics Dashboard](dashboard.png)

## Business Objective
To provide a consolidated view of e-commerce performance and help identify sales trends, customer ordering patterns, and payment preferences.
