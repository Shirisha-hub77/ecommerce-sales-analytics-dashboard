# E-Commerce Sales Analytics Dashboard

![E-Commerce Analytics Dashboard](dashboard.png)

## Project Overview
An interactive E-Commerce Sales Analytics Dashboard built using Microsoft Excel to analyze sales performance, order trends, delivery efficiency, and payment preferences.

## Dashboard KPIs
- **Total Revenue:** 15,209,427
- **Total Orders:** 1,000
- **Average Delivery Time:** 5.55 days
- **Average Order Value:** 5,201.42

## Key Features
- Sales analysis by city
- Average quantity comparison by city
- Monthly sales trend analysis
- Payment mode distribution
- Interactive filters for city, category, and payment mode

## Tools & Technologies
- Microsoft Excel
- Pivot Tables and Pivot Charts
- Excel Slicers
- KPI Reporting and Data Visualization

## Business Objective
To analyze e-commerce sales data, identify monthly sales trends, compare city-level performance, and understand customer payment preferences to support data-driven business decisions.

## Key Insights
- Compare sales performance across six cities.
- Analyze monthly sales fluctuations.
- Compare average order quantities across cities.
- Examine the distribution of four payment methods.

## Dashboard Preview
The dashboard provides a consolidated view of sales KPIs, city-level performance, monthly trends, and payment mode distribution.
